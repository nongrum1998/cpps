# AGENTS.md

CSSP Mobile — the "Pension" app. Expo SDK 57 (React Native 0.86, React 19.2)
managed workflow, TypeScript strict, expo-router file-based navigation, pnpm.
No native `ios`/`android` dirs in the repo (generated by EAS/prebuild).

## Commands

| Command                                                                              | What it does                                                    |
| ------------------------------------------------------------------------------------ | --------------------------------------------------------------- |
| `pnpm dev`                                                                           | Start Metro dev server (`expo start --clear --localhost`)       |
| `pnpm test` / `pnpm test:watch` / `pnpm test:coverage`                               | Jest via jest-expo                                              |
| `pnpm lint`                                                                          | ESLint check + Prettier check (both, one command)               |
| `pnpm format`                                                                        | ESLint `--fix` + Prettier `--write`                             |
| `npx tsc --noEmit`                                                                   | Typecheck — there is **no** `typecheck` script; don't guess one |
| `node scripts/generate-feature.js`                                                   | Scaffold a new feature slice                                    |
| `pnpm preview` / `pnpm preview:local`, `pnpm development` / `pnpm development:local` | EAS Android APK builds                                          |

Finish with `npx tsc --noEmit` → `pnpm test` → `pnpm lint`.

## Layout

- `src/app/` — expo-router routes. Root `_layout.tsx` mounts `ProviderWrapper`
  (gesture-handler, safe-area, root-detection gate, query client, auth,
  redirects). Files here map directly to routes — no central nav config.
- `src/features/<feature>/` — feature slices: `components/`, `hooks/`,
  `screens/`, `store/` (zustand), `types/`, `utils/constants/`,
  `validators/` (zod). Each folder has a barrel `index.ts`; import through the
  barrel, never deep paths.
- `src/shared/` — cross-cutting: `components/` (common/layout/providers/screens/
  ui), `hooks/`, `lib/encryption`, `stores/`, `utils/` (http client, ENDPOINTS
  registry, logger), `validation/` (shared zod schemas).

## Conventions

- Use tsconfig path aliases (`@components/*`, `@features/*`, `@hooks/*`,
  `@utils/*`, `@lib/*`, `@styles/*`, `@stores/*`, `@validation/*`,
  `@sharedTypes/*`, `@config/*`, `@assets/*`) — they map into `src/shared/` and
  `src/features/`. Avoid relative imports across slices.
- Styling: NativeWind 4 (Tailwind) via `className`. Keep `babel.config.js`
  intact — `react-native-worklets/plugin` is required by reanimated/worklets,
  and the `nativewind` jsx import source.
- API paths: reference `ENDPOINTS`
  (`src/shared/utils/constants/endpoints.ts`) — never hardcode URL strings.
  The app-wide axios client is `src/shared/utils/http/client.ts` (JSON, auth +
  token-refresh interceptors).
- JSDoc all exported functions/hooks/components (repo-wide style). Commits are
  Conventional Commits.
- New features: `node scripts/generate-feature.js` scaffolds the slice, then
  wire the screen into `src/app/`.

## Environment

- Env vars are `EXPO_PUBLIC_*`, inlined at build time:
  `EXPO_PUBLIC_API_URL` (main API), `EXPO_PUBLIC_DAT_API_URL` (pension
  statements), `EXPO_PUBLIC_FERNET_KEY` (payload encryption),
  `EXPO_PUBLIC_PPO_NO`, `EXPO_PUBLIC_TEST_IMAGE`.
- Dev requires a local `.env` (copy `.env.sample`); `API_BASE_URL` reads
  `EXPO_PUBLIC_API_URL` and is undefined without it.
- `APP_VARIANT` (injected by `eas.json` profiles) drives the bundle ID suffix,
  app display name, and allows cleartext HTTP only outside production.
- pnpm blocks native module postinstall scripts by default: new deps needing
  them must be added to `pnpm-workspace.yaml` `allowBuilds`.

## Testing

- Jest only collects `*.test.ts` under `src/features/**/test/**` and
  `src/shared/**/test/**` — tests go in `test/` folders, not `__tests__/` or
  colocated. Shared tests currently live in `src/shared/test/` (note the
  misspelled `validiation/` folder — it still matches; keep it under a
  `test/` dir if renamed).
- Suites cover zod validators, zustand stores, and hooks, using
  `renderHook`/`waitFor` from `@testing-library/react-native`.
- `test/setup.ts` mocks `expo-application` and `expo-device`; mock other native
  modules per suite.
- Keep the `transformIgnorePatterns` allowlist in `jest.config.js` — the
  `.pnpm` entry is required for pnpm's symlinked node_modules under jest-expo.

## Security (production-critical)

- `RootProvider` / `useRootDetection` (`jail-monkey`) blocks jailbroken/rooted
  devices and debugger-attached processes in production; bypassed in `__DEV__`
  and fails closed. Do not weaken the gate.
- `usePreventScreenCapture()` is mounted globally in `ProviderWrapper` — keep it.
- Sensitive request payloads are Fernet-encrypted
  (`src/shared/lib/encryption`, key from `EXPO_PUBLIC_FERNET_KEY`).
- Cleartext HTTP is disabled in production
  (`usesCleartextTraffic: false` in `app.config.ts`).
